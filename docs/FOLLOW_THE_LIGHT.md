# Follow the light: FindTrail visual direction

Deep pine surfaces, warm brass controls and entryway photography tie together the search journey. The first unchecked spot sits slightly above the other checklist rows. Found gets warmer light, and Reset opens on a quiet lake with the next step visible below it.

## The screen contract

| Stage | One question or action | Supporting information |
| --- | --- | --- |
| Home | Choose the missing item or resume the saved trail | Last found place stays secondary |
| Saved spot | Check where the item usually lives | Continue to the clue questions if it is missing there |
| Clues | Answer the current clue, or start with likely places | Prior answers stay in a small context strip |
| Trail | Check the current place, then move on or mark found | Why this place, read aloud, voice, and Reset stay available |
| Wider pass | Start the next useful area | Previous progress and skipped places remain accessible |
| Still missing | Do one recommended next move | Additional recovery choices remain below |
| Found and history | Save where it turned up | Reusable home spots build future routes |
| Reset | Return to the next unchecked spot | Breathing is optional; leaving never advances the trail |
| Settings | Tune guidance, accessibility, and private data | Existing backup and offline controls remain |

## Interaction rules

- Main actions have brass faces and secondary actions have pine faces. Both sink slightly while pressed.
- The experience stays readable at 320px, large text, reduced motion, and offline.
- Reset guides three breaths, each with six seconds to inhale, two to hold gently, and eight to exhale. The inhale draws the fog toward the foreground and clears it. On the exhale, fresh ripples spread outward and carry fog back over the cove, where it gathers for the next breath. Home and the active trail are available throughout. After the third breath, Reset shows the next unchecked spot when there is one.
- Saved spots and found history live on the device and use the existing storage format.

For items that can need safety guidance, the clue questions still come first.
